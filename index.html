Inkbolt: local vector and raster editing for AI agents

Inkbolt is a graphics engine for AI agents. Claude Code or another MCP client creates diagrams, illustrations, layouts and image assets on your own machine: it imports SVG and images into an editable document, changes items by id, previews the result as an image, and publishes SVG, PNG, JPEG, TIFF or PDF files without overwriting anything. Every saved edit has a revision, so the agent can retry a request safely, compare revisions or undo a change. It is a single Rust executable with a local MCP server over stdio and a JSON command line, free and MIT-licensed, with no account, network service or telemetry.
