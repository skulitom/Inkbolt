# Native artwork ink planes

`document.prepress` reads vector and raster artwork and returns scalar CMYK and spot plates without changing its source. `pdf_options.prepress` delivers those exact planes in flattened PDF pages with optional physical crop and registration marks. Independent acceptance verification covers `vector.prepress.extended`; the total is **160/167 (95.81%)**. See [IMPLEMENTATION.md](IMPLEMENTATION.md) for the seven remaining unchanged checkpoints.

Supply `options.profile` as an explicit bidirectional CMYK output ICC profile, using the same embedded or pinned-file source as CMYK print delivery. `intent` accepts relative or absolute colourimetric, perceptual and saturation. Perceptual/saturation connections use declared tables and the v4 reference-medium bridge; v2 connections retain direct PCS values. Profiled source paints and images preserve their original values and precision. Physical adjustment observation stays colourimetric before re-separation with the chosen print intent; receipts distinguish both steps. This zero-component rule does not apply to converted RGB/gray/Lab paints or to a spot's zero tint. Unaddressed ink retains its premultiplied amount as shared alpha increases. Receipts identify the exact profile and interleaved sample bytes. The ICC profile is used for conversion, not embedded into scalar plates.

## Shared masks and layer clipping

Shared vector/text artwork masks now supply alpha or encoded-sRGB luminance coverage before native ink delivery. Source groups, gradients, clips, linked/unlinked placement and independent region transforms use the existing [artwork mask contract](ARTWORK_MASKS.md). The scalar mask stays in binary64 until final ink projection. A mask's named paints use their declared display interpretation; a named process paint without its required preview, or overprint inside a mask source, fails explicitly. Mask-source spots do not allocate printed plates. An item still cannot combine grid and artwork opacity masks.

Raster clipping stacks preserve the base layer's intrinsic alpha. Clipped siblings apply their own opacity and masks, followed by the base's controls once for the completed stack. Isolated group bases retain the union of their children's coverage. An opaque background applies its source controls before filling the matte; clipped siblings then see the opaque canvas, including outside the original source extent. Hidden bases suppress their clipped siblings. Existing contiguous-sibling and isolated-container rules remain in force; see [LAYER_CLIPPING.md](LAYER_CLIPPING.md).

Native overprint tracks the backdrop contribution independently for every ink, alongside shared coverage alpha. Thus an overprinted spot can retain process ink through a transparent base, its clipping stack and a pass-through parent. Isolated groups still composite as completed units.

Plane and PDF-page `coverage_sources` receipts retain mask definitions, clipping bindings and evaluation rules. Each mask has `source_sha256` for its source items/font dependencies and `evaluated_source_sha256` for its placed, palette-resolved items. Shared palette edits can change the latter while leaving the former unchanged. Both refer to evaluation inputs; editable sources remain intact. Aggregate mask coverage is limited to 1,048,576 samples, with group, clipping-stack, mask preparation and supersampling buffers/work charged before allocation.

`tests/test_native_coverage_cli.py` covers independent discrete coverage probabilities, scalar luminance equations, transforms, group unions, opaque backgrounds, palette receipts, artboard bleed, exact PDF bytes, cancellation and durable agent history. A separate 72-case exact rational check covers 11,520 continuous ink values across mask modes, clipping, overprint policies and isolated/pass-through parents. Its delivered bytes match both the rational reference and an independent native PDF consumer exactly. These checks join the complete extended print-preparation acceptance evidence.

## Native blend modes

Native preparation supports all 26 engine blend modes with explicit device-ink rules. Separable modes complement subtractive components before and after the existing color function. Hue, saturation, color and luminosity use complemented CMY triples; black comes from the backdrop for the first three and from the source for luminosity. The project `darker_color` and `lighter_color` extensions select a complete CMYK tuple by total ink, with the backdrop winning the same bounded ties described in [BLENDING.md](BLENDING.md). These are device-space operations; no RGB preview or spectral conversion is substituted for stored ink values.

Named inks use a mode only when it is separable and preserves white, meaning `B(1,1)=1` in additive coordinates. Difference, exclusion, subtract and the six whole-color modes therefore use Normal on spot components. Overprint first forms the compatible non-isolated source against its actual backdrop, then applies the requested blend. Simply leaving unaddressed channels untouched after arbitrary blending would give different results. Isolated groups blend as completed units; pass-through children see the surrounding colors. Pass-through groups themselves still require Normal.

Layer clipping blends conditional base colors while preserving intrinsic base alpha. Source and base controls retain the order described above. Opaque backgrounds blend against their matte before clipped siblings. Fill and stroke remain separate Normal paints assembled before the combined item blend and outer controls; this explicit project contract does not claim the special behavior of a combined PDF fill/stroke operator. Geometry antialiasing, masks and image-profile conversion precede final byte projection. Additional backdrop surfaces and blend work consume the existing aggregate budgets. Plane `compositing.blending`, PDF-page `blending` and capability receipts state these rules.

`tests/test_native_blending_cli.py` checks exact rational color grids, singular endpoints, black handling, spot fallback, implicit overprint, transparent groups, nested pass-through masks, clipping, opaque backgrounds, delivery and history. Independent hand-built PDF comparisons preserve consumer discrepancies: the first reader differs by at most 3 byte levels for separable standard modes and up to 7 for translucent nonseparable modes. A second reader differs by at most 2 for the tested process-only cases without nonzero overprint, but up to 21 for implicit nonzero overprint. Expressing those overprint sources explicitly according to the public group equations brings its difference back within 2. These are measured reader limits; the continuous rational contract and exact delivered ink samples are checked separately. Universal page-rendering equality is not claimed. The remaining native contexts still prevent full checkpoint credit.

## Retained image sources

Placed RGBA8 assets work in vector and raster documents; inline RGBA8 and normalized RGB/grayscale sample grids retain their existing raster-document boundary. Sample grids preserve u8, u16 or float32 values, alpha and any assigned RGB profile. Untagged grids and ordinary imported assets use their declared encoded-sRGB interpretation. Native preparation connects tagged source values directly to the printing profile, without converting them through a clipped display preview. Raster background mattes convert once beneath the source; hidden background layers suppress the matte.

Nearest, bilinear, area, bicubic and Lanczos3 reconstruction operate on associated source RGB values. The reconstructed straight RGB is separated before intrinsic alpha, fill/overall opacity, scalar masks, clips and normal group composition. Process images knock out spot amounts at that resulting alpha. Crops, affine placement, components and selected artboards share the existing geometry. Original image/profile bytes remain unchanged. The `image_sources` receipt records source identity, depth, sampling space, profile hash and conversion order; PDF pages carry the same receipts and exact ink-plane samples.

Original tests in `test_native_images_cli.py` and `test_native_profiles_cli.py` check source precision, adjacent 16-bit/float values, direct wide-profile conversion, independent sampling kernels, all supported curve types/stage orders, explicit Lab boundaries, stored-resource failures, cancellation, snapshots/history and exact PDF transport. Independent color checks compare original charts using source-to-XYZ and output-table APIs with the declared PCS boundary. A separate full-transform comparison records consumer differences at out-of-range Lab coordinates. Tensor interpolation is separately checked against exact product-polynomial fixtures; other interpolation algorithms can produce different interior values.

## Flattened native delivery

For PDF export or create-only publication, supply `pdf_options.prepress.profile` with the same explicit CMYK profile. Optional `intent`, `raster_scale` and `antialias` match plane inspection. Select ordered pages with the ordinary `pdf_options.artboards` and `include_bleed`. Components expand before board selection, including definitions stored outside the selected subtree. A file profile is checked and pinned once for all selected pages. `print`, `ink_recipe` and `prepress` are mutually exclusive preparation modes; `color` remains its default `display` value when using `prepress`.

The PDF contains one opaque NChannel image per page, with four process components followed by the used spot identities. Its uncompressed image samples are exactly the interleaved plane bytes returned by `document.prepress` for the same scope and sampling settings. There is no image alpha mask or live transparency group. Original geometry, text, transparency and overprint have become independent ink amounts at the selected density. Keep the source snapshot and resources for editing; this mode does not claim editable PDF reimport.

The exact supplied ICC bytes define the calibrated CMYK alternate and the NChannel process space. Direct CMYK ink numbers remain intact. When spots are present, explicitly choose `spot_fallback:"multiplicative_declared"`. For each process component, this alternate appearance uses `1 - (1 - process) * product(1 - spot_tint * declared_alternate)`. Declared RGB, gray or Lab alternates convert through the same profile; native CMYK alternates retain their components. This is an explicit display fallback, without spectral or press certification. The original spot planes remain separate from that fallback.

## Native knockout and seeded coverage

Isolated and pass-through knockout groups retain each child's footprint separately from its final alpha. The footprint begins with intrinsic paint or reconstructed image alpha and includes the union of nested child footprints. Item opacity and fill opacity attenuate alpha while retaining that footprint: a visible zero-opacity object can cut a hole, whereas intrinsically transparent or hidden artwork cannot. Child blends use the saved group-entry backdrop; isolated groups start transparent. This is the original [knockout contract](KNOCKOUT.md), applied to continuous process and named ink amounts.

Geometric clips, frame clips and scalar/artwork masks attenuate both shape and alpha. Clipped siblings change conditional base colors while preserving the base footprint. Outer group controls apply once after its contents, including zero-opacity descendants. The footprint therefore cannot be reconstructed from the group's final alpha.

Seeded dissolve uses the existing SHA-256 item-local unit-cell threshold. The same threshold is compared independently with the masked footprint and effective alpha after item/fill opacity. Alpha remains contained in the footprint; selected ink fractions and overprint retention stay continuous until final output projection. Transforms and supersampling retain local-cell placement. Native preparation charges shape buffers and both threshold evaluations against its existing aggregate limits; effectively hidden groups do not allocate shape tracking.

Capabilities expose `coverage_composition`; plane and PDF-page `coverage_sources.composition` repeat the same rules. Original conditional-probability tests cover every blend mode, all overprint policies, process and spot paints, nested group combinations, masks, clipping, reconstructed image alpha, zero opacity, fractional edges, dissolve, resource rejection and durable history. The current source context and adjustment contracts are described below; registry status governs checkpoint credit.

Original fixtures and discrepancies remain retained. These are measured reader differences, not universal transparency-rendering agreement or changes to the engine's footprint contract.
