# Render quality and effect bounds

HDR working-space rendering and explicit views follow [HDR.md](HDR.md). Linear radiance is averaged before tone mapping.

Explicit-depth TIFF output uses the same completed f64 samples before projecting to 8-bit, 16-bit or binary32 output. Ordinary PNG/JPEG/previews and TIFF without depth/channel options retain their RGBA8 behavior. See [SAMPLES.md](SAMPLES.md); output-profile conversion remains unavailable on the explicit-depth path.

Agents can choose image resolution, geometric antialiasing, sample averaging and an explicit effect evaluation margin without editing the source document. `render_options` works on `document.render`, `document.export`, `artboard.export` and inside `output` for `document.publish`/`session.publish`. Image delivery supports PNG, JPEG and TIFF. SVG, PDF and snapshot delivery reject this object because they retain their separate geometry and format contracts.

```json
{"scale":2,"render_options":{"antialias":"supersample4","averaging_space":"encoded_srgb","padding":16,"crop_to_canvas":true}}
```

This evaluates eight samples per document unit along each axis, includes a 16-unit margin on every side, averages each 4 by 4 block and returns the original canvas at twice its logical dimensions. Every setting is optional; omitting `render_options` selects ordinary coverage with no padding.

| Setting | Values | Meaning |
| --- | --- | --- |
| `scale` | Integer 1..4, default 1 | Output pixels per document unit. Image density is `document.resolution_ppi * scale`, with the existing format rounding. Supersampling does not change output density or dimensions. |
| `evaluation` | `whole` (default), `tiled` | Existing whole-image evaluator or explicit bounded regional composition; tiled restrictions and bounds are below. |
| `antialias` | `none`, `coverage` (default), `supersample2`, `supersample4` | Binary geometric coverage, existing backend coverage, or 2 by 2 / 4 by 4 completed coverage samples per output pixel. |
| `averaging_space` | `encoded_srgb` (default), `linear_srgb` | Space used only to average supersamples. Linear averaging requires supersampling. Scene blending, filters and effect color calculations retain their encoded-sRGB contracts. |
| `padding` | Integer 0..256, default 0 | Extra document units evaluated outside every original canvas edge. Includes off-canvas source artwork. |
| `crop_to_canvas` | Boolean, default true | Crop the completed evaluation back to the original canvas, or return the full padded extent. |

Geometry, text outlines, image boundaries, frame clips, geometric clips and artwork-mask region clips share the antialias choice. `none` disables geometric smoothing; source image alpha, paint transparency, grayscale masks, blur and filtering can still produce intermediate alpha. Image reconstruction retains each item's nearest/bilinear/area/bicubic/Lanczos3 setting; it is distinct from geometric antialiasing. Supersampling also samples gradients, image colors, masks and the complete scene at the higher resolution.

Completed samples stay in premultiplied f64 until averaging. For encoded averaging, sum associated RGB and alpha and divide RGB by summed alpha. For linear averaging, decode each nontransparent sample's straight RGB with the sRGB transfer curve, reassociate it with alpha, average, then encode the final straight color. There is one final RGBA8 rounding; an alpha byte of zero has transparent-black RGB. Averaging straight colors independently would introduce fringes and is not used. Image output profile conversion follows this RGBA8 projection, using the existing explicit RGB profile and intent; see [COLOR_PROFILES.md](COLOR_PROFILES.md). For JPEG, the explicit matte composites in encoded sRGB after RGBA8 projection and before output-profile conversion; compression follows. See [IMAGE_IO.md](IMAGE_IO.md).

Ellipses use an original 32-arc tangent-matched cubic outline before backend coverage at every quality setting. Controls are placed in binary64 before one conversion to output-space binary32. Analytic source ellipse parameters, snapshots and SVG ellipses remain unchanged; corrected placement and the more detailed default outline can change edge pixels. These are finite approximations: neither supersampling nor the coverage backend promises exact geometric area for arbitrary curves, extreme coordinates or repeated overlaps.

Padding changes the evaluation viewport, then optionally discards its outer samples. For example, a shadow cast into the canvas by a shape just outside it becomes visible when that source and its required filter neighborhood fit inside the margin. Padding is explicit; Inkbolt does not infer a sufficient margin for an arbitrary ordered effect stack. Filter borders apply to the padded viewport. An insufficient margin still truncates support. Frames/artboards retain their authored clipping; padding cannot undo those clips. An opaque background role fills the evaluation viewport. Viewport-anchored noise and mosaic cells rebase to the padded upper-left corner; seeded behavior remains repeatable for identical settings. Paints, local dissolve cells, linked/unlinked masks, artwork sources and component placements retain their declared coordinate relationships.

`render_settings` reports the selected modes, output scale, internal scale, padded evaluation dimensions, output dimensions and output origin in document units. The origin is `[0,0]` when cropped and `[-padding,-padding]` otherwise. Publication receipts and descriptive image metadata retain these settings and actual output dimensions. For an artboard, this origin is relative to the independent board/bleed viewport; the existing `source_bounds` and `trim_box` still describe that viewport before optional render padding. Snapshots remain the editable source and do not store transient delivery settings. Locked artwork is renderable without mutation; source pixels, assets, fonts, selections, channels, revision and persistent history remain unchanged.

All padding and supersamples count against the selected evaluation-pixel limit: 1,048,576 for default `whole`, 16,777,216 for explicit `tiled`. Compositing-buffer and paint/filter/effect/text/outline work limits still apply. Internal scale is at most 16. Artboard ranges account for the full evaluation domain before returning artifacts and keep their existing 4,194,304 aggregate-pixel limit; an error returns no partial range. Enlarged bounds or translated controls outside declared document limits fail explicitly. Publication stays create-only and respects cancellation before its commit point. No output-quality setting bypasses resource or publication checks.

## Bounded tiled evaluation

For a full-size image use, for example, `{"format":"png","render_options":{"evaluation":"tiled"}}`. Scene expansion, fonts, scalar masks and resource resolution occur once per render. The compositor visits evaluation-pixel tiles of at most 128×128 (smaller at edges), with original global sampling coordinates for paints, images, clips, masks and dissolve cells. Supersampling reduces the number of finished output pixels per tile. Whole and tiled modes share completed premultiplied sample averaging, fractional-canvas coverage, HDR views and one final depth projection. `render_settings` explicitly reports `evaluation:"tiled"` and `evaluation_tile_edge:128` as the maximum, plus `evaluation_tile_policy:"maximum_128;8_for_at_least_128_expanded_items"`; omitted/default options preserve existing receipts.

Tiled evaluation currently rejects any item with filters, effects or an artwork-mask reference, plus raw-development and retained-object content, with `UNSUPPORTED_TILED_RENDER`. Disabled/hidden instances of those controls also reject. Scalar masks remain supported, including their already prepared native feathering. The existing whole evaluator retains its supported combinations. No implicit fallback allocates a full floating-point image. The Rust API returning a complete native `SampleRaster` remains whole-only; native TIFF consumes the regional visitor directly.

Inline native grids decode once for the prepared scene. Immutable byte assets retain their byte buffer, with linear conversion at sampled taps. Stored native grids share the bounded decoded-tile cache described in [native storage](NATIVE_SAMPLE_STORAGE.md); repeated cache misses can still reach its explicit decode-work limit. Scenes with at least 128 expanded items use an 8×8 spatial index. Conservative transformed control bounds and descendant unions retain original composition order, isolation, knockout, scalar masks and clipping adjacency. World transforms and clipping bindings are prepared once. Curves, stroke outlines, glyphs and ordinary clips retain bounded shape coverage so small compositor tiles do not independently clip those curves. Compound clips retain their original boolean evaluator. The index and coverage are rebuilt for each prepared render, including historical or edited revisions; there is no persistent cache.

The index allows at most 1,048,576 item-to-cell memberships; prepared shape coverage allows at most 16,777,216 aggregate alpha pixels. Its retained storage and preparation scratch count against the existing aggregate render memory limit. Visited tile pixels, padding alignment, outline scans, paints, reconstruction and coverage preparation count against the existing work limits. Dense overlaps still fail explicitly. Neither the item-count profile nor tiled mode increases those independent budgets.

RGBA8 output retains one complete final byte image (at most 64 MiB), plus bounded composition and codec buffers. Small tiles visit neighboring regions of at most 256 document units per axis, with completed bands delivered from top to bottom. The sampling/composition grid is unchanged; ordering improves source-block reuse without allocating a larger floating-point surface. Output scale controls the corresponding pixel span; supersampling keeps the same logical neighborhood. `evaluation_neighborhood_units:256` records this policy. Explicit-depth TIFF assembles bands independently of the composition-tile height, limited to 16 MiB and shortened to fit the existing tile grid, then projects each sample once to the requested depth. Final partial bands are fully populated before compression. The locked external codec compresses each strip through its public compression API; no compression implementation is copied into the engine. None/LZW/Deflate, RGBA/gray-alpha and u8/u16/f32 retain existing meanings. Encoded output is limited to 32 MiB; TIFF enforces this while writing and PNG checks before base64 delivery. TIFF compression may use additional bounded strip scratch. These are component bounds, not measured whole-process memory guarantees. Cooperative cancellation and `render_tiles` progress checks occur between tiles; publication still has its existing final commit gate.

`tests/test_tiled_render.py` checks complete 1080×1080 and 2480×3508 PNG pixels and every native channel of a 1920×1080 TIFF. Smaller fixtures cover multiple strips, independent uncompressed/Deflate TIFF decoding, LZW codec round trips, HDR, all native layouts/depths, all samplers, masks/groups/clips, fractional canvas, dissolve, curve/stroke and warp boundaries, artboards, rejection and no partial publication. `tests/test_spatial_render.py` additionally checks all pixels of 5,001 mixed objects, whole/indexed equivalence for text, strokes, cropped images, warps, groups, clipping, masks, knockout and native strips, plus source-preserving revision changes and dense-scene rejection. `tests/test_native_locality.py` preserves every native channel in a 2560x1440 source with 128 clipped annotations through local edits and historical output; it also checks wide thin sources, scale, padding, supersampling, reconstruction halos, partial strips and all depth/channel/compression combinations. These fixtures do not promise bit-identical edge coverage for all arbitrary geometry, establish measured scale gates, or complete A5.

`tests/test_render_quality_cli.py` verifies exact rational triangle/pixel intersections, analytic rectangle area, independently integrated ellipse slices, exact premultiplied color/alpha averages, independently convolved shadows and blur, font outlines, masks, component definitions, profiles, density, artboard order/bleed, metadata, source preservation and durable agent publication. At 4 by 4 sampling the original fractional rectangle fixture differs from exact area by at most one alpha byte; triangle and small-ellipse fixtures use at most three alpha bytes. These are fixture tolerances, not universal error guarantees. Separate external decoder evidence checks PNG/TIFF pixels and profiles exactly and JPEG with explicit fixture error/PSNR limits.
