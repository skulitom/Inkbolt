The following implementation notes were preserved from the README on 9 October 2026. Historical percentages and limitations describe their original updates; [features.json](features.json) and the current feature contracts govern present status.

The full resource checkpoint remains partial; the verified total stays **161/167 (96.41%)**. See [stroke precision](STROKES.md).
