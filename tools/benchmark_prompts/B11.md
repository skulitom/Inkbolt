# B11: Revise a mixed masked/effect document (prompt version 1)

Preserve `original.png` and this prompt unchanged. The source is an original
32 by 24 pixel RGBA8 image. Build this editable composition, from bottom to top:

1. The pinned original image at its native size and position.
2. An isolated group, opacity 0.75, with a linked full-canvas scalar mask:
   coverage 128 for x < 16, otherwise 255. Its sole child is a vector rectangle
   (x=8,y=6,width=12,height=10), fill RGBA (30,150,70,173), fill opacity 0.5.
   Give the child one shadow: black RGBA (0,0,0,128), offset (3,2), sigma 0.
3. An unrelated vector rectangle (25,2,4,4), opaque RGBA (220,90,30,255).

Use normal source-over, identity transforms and default remaining properties.
Review and change only the shadow offset to (5,-1). Keep the image binding, mask,
group isolation/opacity, fill opacity, geometry, order and all other properties.
Do not flatten the editable controls into a replacement image.

For pixel interpretation, the shadow derives from the child's fill alpha 173/255
before its separate fill opacity. Composite the shadow behind the half-opacity
fill within the isolated group, then apply the group's mask and opacity to that
group result. Composite it over the source, then the unrelated orange rectangle.
Keep intermediate precision; round the final straight RGBA channels to nearest
8-bit values. Bounds are zero-based and include the top/left, exclude bottom/right.

Deliver and review the complete final `preview.png` (32 by 24). Use new files.
With Inkbolt, use a raster document with the `large_raster` resource profile.
Choose your own document, item, effect, asset-binding, session and request IDs.
Save the original composition as revision zero and deliver `before.json`.
Review/apply the edit, deliver the current `editable.json` snapshot, and deliver
and review `historical.png` from the original saved revision. Verify history.
The current snapshot must match the final session head. Deliver `session.json`
containing exactly `session_id`, `original_revision` (0), and `current_revision`.

For the no-engine baseline, retain the vector, group and shadow controls in
`editable.json` using the exact manifest below; substitute the actual SHA-256
of `original.png`. The group mask stays separately editable as `mask.png`, a
single-frame, opaque grayscale PNG, 32 by 24, at most 64 KiB. RGB/RGBA grayscale
or L mode is accepted. Do not add other paths, transforms, resources or effects.

```json
{
  "width":32,"height":24,
  "image":{"file":"original.png","sha256":"SHA-256 of the unchanged source"},
  "group":{"isolated":true,"opacity":0.75,"mask":{"file":"mask.png","linked":true}},
  "art":{"bounds":[8,6,12,10],"fill":[30,150,70,173],"fill_opacity":0.5,
         "shadow":{"offset":[5,-1],"sigma":0,"color":[0,0,0,128]}},
  "unrelated":{"bounds":[25,2,4,4],"fill":[220,90,30,255]}

```

Use the pinned Python/Pillow environment and ordinary file/shell tools. Numeric
processing before final image encoding is permitted to preserve the specified
intermediate precision. The judge reopens the retained image/mask with pinned
Pillow, freshly composes the editable controls and checks both it and your PNG
against the same exact numerical oracle used for Inkbolt. Saved-revision pixels
and session integrity are separate engine-only checks, not applicable here.
