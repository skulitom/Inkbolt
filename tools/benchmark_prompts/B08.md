# B08: Select and mask a foreground region (prompt version 1)

Open `source.json`, an original 16 by 16 pixel raster document with one layer,
`pixels`. Preserve its bytes and this prompt. Select the L-shaped foreground
polygon (4,3), (12,3), (12,7), (8,7), (8,13), (4,13) and attach a linked editable
mask. Retain the complete original layer, including every unselected pixel, and
retain the selection independently. Keep all other document state unchanged.

The source JSON's `items[0].content.rgba_hex` contains row-major RGBA8 samples.
At integer coordinate (x,y), the original sample is (11*x,13*y,7*(x+y),255).
Coverage is 255 when a pixel's center lies inside the polygon and zero otherwise:
there is no feathering or partial edge coverage. The mask is linked to the layer
so they share its transform. Do not erase or replace the original layer samples.

Deliver and review `preview.png`, the complete 16 by 16 transparent RGBA image.
Selected pixels retain their exact original samples; unselected output pixels
are (0,0,0,0). Use new output files without overwriting existing files.

With Inkbolt, save the original as revision zero of a session, perform the edit
and publish the final snapshot as `editable.json`. Keep the original revision
accessible, deliver and review its complete `historical.png`, and verify history.
Choose your session name, request IDs and number of editing steps. Equivalent
mask storage extents are allowed; source preservation, selection and final pixels
are checked independently. The snapshot must match the session's current revision.
Deliver `session.json` with exactly `session_id`, `original_revision` (0) and
`current_revision`, using your actual values.

For the no-engine baseline, read the same JSON and retain `pixels.png` containing
all original RGBA samples, plus separate `mask.png` and `selection.png` coverage
images. Deliver this exact editable layer manifest as `editable.json`:

```json
{"width":16,"height":16,"id":"pixels","image":"pixels.png","mask":"mask.png","selection":"selection.png","linked":true,"transform":[1,0,0,1,0,0]}
```

The single transform belongs to the linked layer and mask; the selection stays
in document coordinates. Each component is a single-frame 16 by 16 PNG at most
64 KiB, in 8-bit grayscale, RGB or RGBA form. Mask/selection PNGs encode coverage
as gray values, with equal RGB channels and fully opaque alpha if present.
Their gray samples must match the selected foreground exactly. Image paths and
manifest fields are fixed as shown; do not add resources or flatten this bundle.
Use the supplied pinned Python/Pillow tool to compose a fresh preview, setting
unselected RGBA samples to zero. The judge independently decodes and composes the
retained layer/mask with the pinned tool, then compares both that result and the
delivered preview with the same pixel oracle used for Inkbolt. Saved-revision
pixels and session integrity are separate engine-only checks, reported as not
applicable in the baseline.
