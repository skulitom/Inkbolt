# B09: Retouch a local image defect (prompt version 1)

Open `source.json`, an original 16 by 16 pixel raster document with one layer,
`pixels`. Preserve this source file and prompt unchanged. Repair the 2 by 2 defect
at (10,10) by cloning the original same-layer patch at (2,2), using nearest
sampling. Coordinates are zero-based pixel coordinates; both patches include
their top-left pixel and the following row and column. Copy RGBA samples exactly.
Keep every other pixel and all other document properties unchanged.

The source's `items[0].content.rgba_hex` contains row-major RGBA8 samples. The
defective four pixels are magenta (255,0,255,255). The surrounding pattern and the
source patch are original evidence; do not replace the image with a flat fill,
blur, rescale, or modify pixels outside the requested repair.

Deliver and review `preview.png`, the complete repaired 16 by 16 RGBA image.
Retain an editable pixel layer. Use new files without overwriting existing files.

With Inkbolt, save the original as revision zero of a session, make the repair
and publish the current snapshot as `editable.json`. Retain the original saved
revision, deliver and review its complete `historical.png`, and verify history.
Choose your own session and request IDs and number of editing steps. The judge
checks delivered state and pixels independently of your command sequence. The
snapshot must match the session's current head. Deliver `session.json` containing
exactly `session_id`, `original_revision` (0), and `current_revision` with your
actual values.

For the no-engine baseline, decode the same source JSON, clone the patch with
the supplied pinned Python/Pillow tool, and retain the repaired layer as
`pixels.png`. Deliver this exact layer manifest as `editable.json`:

```json
{"width":16,"height":16,"id":"pixels","image":"pixels.png","transform":[1,0,0,1,0,0]}
```

The layer is a single-frame 16 by 16 PNG at most 64 KiB, in 8-bit RGB or RGBA
form. Image path, layer identity, dimensions and transform are fixed as shown;
do not add resources, masks or effects. Render its pixels into `preview.png`.
The judge independently reopens the editable layer with pinned Pillow and checks
both it and the delivered preview against the same complete-image numerical
oracle used for Inkbolt. Saved-revision pixels and session integrity are separate
engine-only checks, reported as not applicable in the baseline.
