# B03: Revise one object in a large layout (prompt version 1)

Open `source.json`, an original 1000 by 500 pixel transparent vector layout with
5,000 blue rectangles. Preserve its bytes and this prompt. Inspect `cell-2473`
and move only that object one pixel right and one pixel down in world coordinates.
Keep every object separately editable, in its original order, with its stable ID,
original local rectangle controls and fill. Preserve all other document state.

The source is plain JSON. Its `items` array contains `cell-0` through `cell-4999`.
For index i, `content.geometry` is a rectangle at ((i % 100) * 10, floor(i / 100) * 10),
width 6 and height 6. `content.fill` is RGBA (20, 80, 150, 255). The original object
transforms are identity. The target retains local (730, 240), 6 by 6 controls and
gains translation (1, 1). It appears at (731, 241) in the final image. There are no
fonts, image assets, strokes or other dependencies.

Deliver and review `preview.png`: the complete 1000 by 500 transparent RGBA image
after the edit. Do not flatten the editable source or change the other 4,999
objects. Use new output files without overwriting existing files.

With Inkbolt, save the original as revision zero of a session, perform the edit,
and publish the final snapshot as `editable.json`. Keep the original revision
accessible. Deliver and review `historical.png`, a complete 1000 by 500 PNG from
that original saved revision, and verify the session history. You choose the
session name, request IDs and number of editing steps. The final snapshot must
match the session's current revision. Deliver `session.json`
with exactly these fields, using your actual session ID and final revision:

```json
{"session_id":"your-session", "original_revision":0, "current_revision":1}
```

For the no-engine baseline, read the same source JSON and deliver `editable.svg`
and `preview.png`. Use a UTF-8 SVG (at most 2 MiB), the SVG namespace, numeric
1000 by 500 dimensions and, if present, a matching `viewBox="0 0 1000 500"`.
Its only children are the 5,000 `rect` elements with the original IDs, order,
x/y/width/height controls and opaque blue fill (`#145096` or numeric
`rgb(20,80,150)`). Only `cell-2473` has a nonidentity
transform: translation (1, 1). Use numeric matrix/translate/scale/rotate syntax
whose resulting matrix is exactly the requested transform. Use presentation
attributes, no strokes, stylesheets, external resources, definitions, document
types or additional elements. The judge renders this source independently with
the pinned rasterizer and compares it and the delivered PNG with the same pixel
oracle used for Inkbolt. Saved-revision images and session integrity are separate
engine-only checks, reported as not applicable in the baseline.
