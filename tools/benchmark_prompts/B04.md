# B04: Import and revise vector artwork (prompt version 1)

Open `original.svg` and retain its layer and separately editable path. Move only
the path four pixels right and one pixel up in world coordinates. Preserve the
original file bytes and this prompt. Inspect and disclose import losses.

The original 32 by 24 transparent canvas contains the description
`Original benchmark description`, a group with source ID `layer` translated by
(3, 2), and its child path with source ID `block`. Retain the path's closed local
controls (2, 3), (10, 3), (10, 9), (2, 9), its opaque blue fill (20, 80, 150, 255)
and no stroke. Keep the group's transform. Give the path translation (4, -1),
so the final world-space blue rectangle is at (9, 4), size 8 by 6. Do not flatten,
rebuild as a rectangle primitive, change its controls or add other artwork.

Deliver `revised.svg` and review `preview.png`, a complete transparent 32 by 24
PNG of the revised artwork. Also deliver `import-report.json` with exactly:

```json
{
  "source_sha256": "the SHA-256 of original.svg",
  "mapping": {"layer": "the delivered layer ID", "block": "the delivered path or path-wrapper ID"},
  "losses": ["source_ids_remapped", "description_omitted"]
}
```

List each loss **only if it occurred in the delivered SVG**: include
`source_ids_remapped` if either ID differs from its source ID, and
`description_omitted` if the original description is absent. Otherwise use `[]`.
Do not invent losses or conceal omissions. The mapping must identify the retained
layer and its path (or a wrapper owning only that path).

With Inkbolt, use `svg.import` and preserve its full returned result object as
`import-receipt.json`, including its complete loss list. Save, edit and publish
the final editable snapshot as `editable.json`, preserving the imported items
and their IDs. You choose the document/session/request names and number of edits.
Its revision must be positive. The judge separately checks the receipt, snapshot,
SVG and PNG; correct solver logs cannot substitute for the delivered files.

For the no-engine baseline, edit the same original SVG directly and render it
with the pinned rasterizer. Retain or honestly report remapped IDs and the omitted
description. The same source, structure, loss-disclosure and pixel checks apply;
the Inkbolt snapshot check is separately reported as not applicable.

The shared SVG delivery subset is UTF-8, at most 1 MiB, numeric 32 by 24 dimensions
and a matching viewBox if present. Use one group/path chain (at most 16 structural
nodes and depth 8), with optional titles and the original root description.
Identity wrappers may enclose the retained layer or path. Use explicit absolute
M/L/H/V/Z commands, numeric matrix/translate/scale/rotate transforms, and an opaque
`#145096` or numeric `rgb(20,80,150)` path fill with nonzero fill rule. Group
`isolation:isolate` is allowed. Do not add stylesheets, definitions, resources,
other elements, document types or changed opacity. Write only new output files.
