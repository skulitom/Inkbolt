# B13: Deliver transparent screen artwork (prompt version 1)

Create a transparent 1920 by 1080 vector screen graphic containing one rectangle
at (10,20), width 200 and height 100, straight RGBA (20,80,150,128). Keep the
background fully transparent, with zero RGB outside the rectangle. Do not add a
matte, stroke, corner radius, extra objects or transforms. Retain an editable
source and the private source metadata note: "original private source note".

Preflight, deliver and review screen.png as single-frame, noninterlaced RGBA8 PNG
with an sRGB declaration. Preserve exact straight-alpha samples: do not silently
premultiply or round-trip through a quantized premultiplied representation.
Strip descriptive/private metadata and embedded ICC profiles from the delivery.
The private note belongs only in editable source. Keep this prompt unchanged.

Use create-only publication. Attempt the same publication again, require an
output-exists refusal, and verify the first PNG is byte-for-byte unchanged.

```json
{"file":"screen.png","mode":"create_only","sha256":"SHA-256 of the first PNG","collision":"output_exists"}
```
