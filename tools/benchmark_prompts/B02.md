# B02: Produce an aligned icon sheet (prompt version 1)

Create an editable 112 by 32 pixel vector icon sheet on a transparent canvas.
There are no source assets. Preserve these stable IDs and their document order:

| Board | Sheet position | Size | Child icon | Local icon rectangle | RGBA color |
| --- | --- | --- | --- | --- | --- |
| board-0 | (0, 0) | 32 by 32 | icon-0 | (12, 11), 8 by 10 | (20, 80, 150, 255) |
| board-1 | (40, 0) | 32 by 32 | icon-1 | (12, 11), 8 by 10 | (30, 150, 70, 255) |
| board-2 | (80, 0) | 32 by 32 | icon-2 | (12, 11), 8 by 10 | (220, 90, 30, 255) |

Each board owns only its one separately editable vector rectangle. Use no strokes,
backgrounds, extra visible objects or font/image dependencies. The boards are
independent viewports, not three regions sharing one combined export.

Deliver and review three independent transparent 32 by 32 PNGs: `board-0.png`,
`board-1.png`, and `board-2.png`. Each contains only the icon belonging to that
board, at the local position above.

With Inkbolt, create three top-level artboard frames and their child vectors,
and publish an editable snapshot as `editable.json`. Its item
order is board-0, icon-0, board-1, icon-1, board-2, icon-2. The document ID,
session name and request IDs are your choice.

For the no-engine baseline, deliver `editable.svg`: an outer 112 by 32 SVG with
three direct child SVG viewports. Give each viewport its board ID, sheet x/y,
32 by 32 width/height, and its one child `rect` with the required icon ID.
Use the SVG namespace, numeric pixel dimensions and matching viewBoxes if present.
Viewport overflow must remain hidden. Rectangle coordinates may use matrix,
translate, scale or rotate transforms that preserve the requested local geometry.
Use presentation fill/stroke/opacity attributes; avoid stylesheets, external
resources, definitions and additional elements. The source judge independently
renders each nested viewport as a standalone board using the pinned rasterizer.
The PNG artifact requirements are identical in both arms; the Inkbolt snapshot
check is reported separately.

Preserve this prompt and any original inputs. Write new output files without
overwriting existing files.
