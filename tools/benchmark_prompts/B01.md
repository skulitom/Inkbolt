# B01: Create a labelled diagram (prompt version 1)

Create an editable 128 by 56 pixel vector diagram on a transparent canvas.
Coordinates below are in canvas pixels; colors are RGBA values.

Inputs in the workspace:

- `original.ttf`: the original synthetic typeface to use for all labels.
- `font-license.txt`: its license, to retain with the font.

Draw a blue rectangle at (8, 8), size 48 by 36, color (20, 80, 150, 255);
a green rectangle at (80, 8), size 40 by 36, color (30, 150, 70, 255);
and a gray connector at (56, 25), size 24 by 2, color (80, 80, 80, 255).
Use no strokes. Add white editable labels in the supplied typeface at size 20:
"AA" in a 32 by 24 text frame at (20, 16), and "A" in a 32 by 24 frame at
(96, 16). Frame positions describe the top left, not the text baseline.
Keep the five objects separately editable. Object and font-binding names are
your choice. Preserve the supplied font and license bytes.

Deliver `preview.png`, a full-size PNG of the completed diagram, and review it.
With Inkbolt, save a session and publish an editable snapshot as `editable.json`.
For a no-engine baseline, deliver editable SVG as `editable.svg`, retaining
text and its supplied font; do not substitute outlined or rasterized labels.
The PNG artifact requirements are identical in both arms; engine-specific
snapshot checks are reported separately.

Preserve all original inputs. Create new output files without overwriting
existing files. Do not leave additional visible objects, backgrounds or marks.
