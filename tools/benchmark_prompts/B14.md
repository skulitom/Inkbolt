and bleed top=9, right=12, bottom=6, left=3 logical pixels. Keep the fractional

- A rectangle (140,30,80,80), spot ID `spot`, full tint, with CMYK alternate
  (0,1,0,0) using the same original-cmyk.icc profile.

Use relative colorimetric intent, black point compensation off, opaque fills,
normal compositing and knockout. Do not add strokes, transforms or other artwork.
Review a 240 by 130 focused display preview at origin (0,0), saved as preview.png.

outside the rectangles. This display preview is not a press proof.

and spot operands. Preserve the RGB page/group blending profile, the CMYK source
profile, and the spot name `Inkbolt.spot`. Embed each original profile once. PDF

[0,0,75600/127+15,106920/127+15], TrimBox is
[3,6,75600/127+3,106920/127+6], in physical points. Keep originals and this prompt
unchanged. Use a new output destination; do not overwrite any source or delivery.

PDF hash) and `losses` (an array of explicit delivery limitations). State that PDF
does not carry the editable document model and that this output is not a print
proof. Retain every engine-reported limitation when using Inkbolt.

display_rgb document color and the specified bleed. Set its native_inks PDF
