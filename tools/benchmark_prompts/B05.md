# B05: Recolor a shared palette (prompt version 1)

Open `source.json`, an original 32 by 16 pixel transparent vector document.
Preserve its bytes and this prompt. Recolor the `shared` swatch from opaque blue
RGBA (20, 80, 150, 255) to opaque orange RGBA (220, 90, 30, 255). Both dependent
rectangles must change together; the unrelated green artwork must stay unchanged.
Keep all other document state, object IDs, order, geometry and transforms.

The source is plain JSON. Its `items` array contains three 8 by 8 rectangles at
y=4: `first` at x=2, `second` at x=12 and `unrelated` at x=22. The first two fills
reference `shared`; the third is direct RGBA (30, 150, 70, 255). The `swatches`
dictionary defines `shared` as a process color in sRGB, with three components
normalized to 0-1 and display name `Shared`. All transforms are identity. There
are no fonts, strokes, image assets or other resources.

Deliver and review `preview.png`, the complete 32 by 16 transparent RGBA image
after recoloring. Retain separately editable rectangles. Use new output files
without overwriting existing files.

With Inkbolt, save the original as revision zero of a session and edit the swatch
definition, preserving both live references. Publish the final snapshot as
`editable.json`. Deliver and review `historical.png` from the original saved
revision, and verify the session history. You choose the session name, request
IDs and number of editing steps. The final snapshot must match the session's
current revision. Deliver `session.json` with exactly these fields, using your
actual session ID and final revision:

```json
{"session_id":"your-session", "original_revision":0, "current_revision":1}
```

For the no-engine baseline, read the same source JSON and deliver `editable.svg`
and `preview.png`. Use a UTF-8 SVG (at most 64 KiB), the SVG namespace, numeric
32 by 16 dimensions and, if present, a matching `viewBox="0 0 32 16"`. Its only
children are the three `rect` elements with the original IDs, order and numeric
x/y/width/height controls. Use opaque `#dc5a1e` or numeric `rgb(220,90,30)` fills
for `first` and `second`, and `#1e9646` or numeric `rgb(30,150,70)` for `unrelated`.
Transforms, if present, must evaluate to identity. Use presentation attributes,
no strokes, stylesheets, definitions, document types, resources or extra elements.
The judge renders this editable source independently with the pinned rasterizer
and compares both images with the same pixel oracle used for Inkbolt. Live
Inkbolt swatch references, saved-revision images and session integrity are
separate engine-only checks, reported as not applicable in the baseline.
