SVG and vector editing MCP servers for AI agents, local and hosted: 9 compared

To let an AI agent edit an existing SVG by element id on your own machine with no account, use Inkbolt (one executable, with saved revisions, undo and PNG previews the agent can see) or an Inkscape MCP server (sandraschi/inkscape-mcp or aravindev/inkscape_mcp, with Inkscape installed); for AI-generated artwork use SVGMaker MCP (an account and credits), and to trace images into SVG use image2svg-mcp. We make Inkbolt: on 18 October 2026 we compared nine SVG and vector MCP tools, measuring Inkbolt over MCP in six runs on Windows and reading the other eight from their source code and docs without running them. The catch with Inkbolt: it imports the SVG into its own document and writes new markup on export, and it won't import text until you supply a font file; the Inkscape servers edit the file's XML directly. In all six runs (the 0.82.0 release and main), importing an SVG, recolouring one shape and moving another by id, resending the edit, undoing it and publishing SVG and PNG gave byte-identical files run to run on each build; the strict import refused an unsupported blur filter with its line and column, a publish over an existing file was refused, and the source SVG was unchanged. Method, sources and data are below.

We make Inkbolt. Read this as a vendor's page: our own numbers come from runs you can repeat, and everything about the other tools links to where we read it. If we got something wrong, open an issue and we will correct it.

The short answer

  • Your agent should change a specific SVG or image precisely (recolour this shape, move that one, check the result, undo a mistake) on your own machine, with no account and no desktop app: Inkbolt. It imports the SVG into an editable document, edits items by id in a saved session with revisions and undo, returns a preview image the agent can see, and publishes new files without overwriting anything. It also edits raster images. It rewrites the SVG it exports rather than patching your markup (details under Inkbolt's limits), an SVG with text won't import until you supply and bind a font file (and its text is exported as outlines), and it is young: version 0.82.0 and 1 GitHub star.
  • You already use Inkscape, or you need its breadth (extensions, path operations, exports to EPS, DXF, EMF or XAML): one of the Inkscape MCP servers. aravindev/inkscape_mcp can also edit the document open in Inkscape's window, with Inkscape's own undo; sandraschi/inkscape-mcp has more tools than aravindev's (19 against 8) and adds AI generation through your MCP client. Most of their operations need Inkscape installed.
  • You want new SVG artwork from a text prompt, or AI vectorisation of a photo or logo: SVGMaker MCP, with an SVGMaker account and credits. Its "edit" re-generates the image from a prompt; it doesn't edit elements.
  • You want to trace a raster image (PNG, JPEG) into SVG with smooth curves, locally and for free: image2svg-mcp (one tool, built on vtracer). Inkbolt's tracer follows pixel edges exactly and does no curve fitting.
  • You want a diagram screenshot rebuilt as editable Visio, PowerPoint or draw.io: LayerBack MCP, hosted and paid per conversion (10 credits).
  • Your artwork lives in Adobe Illustrator: an Illustrator MCP bridge, with Illustrator installed and running. None of the three repositories we read has a licence.
  • svg-maker-mcp and EditItAll are utilities, not editors: the first renders, optimises and converts SVG text the agent writes (its repository has no licence file); the second imports SVG text into a closed web editor, where another tool can screenshot it, with no way to export a vector file.

What we measured on Inkbolt

One editing task, run over MCP the way an agent runs it, on Windows 11 (x64), with the documented launch command inkbolt --workspace <new folder> mcp --tools core. The client is a small Python MCP stdio client. The probe script, the input SVG and every result file are in data/.

  1. The input: an original 240 × 120 SVG diagram made for this test: two rounded rectangles with ids input (filled with a linear gradient) and output, a curved connector link, an arrowhead arrow, and a circle glow blurred by an SVG <filter>. We took its SHA-256 before the server started.
  2. Strict import (the default): refused with SVG_UNSUPPORTED, "Geometry <filter> is not supported", at line 8, column 5.
  3. Import with unsupported: "omit_and_report": four editable shapes under a root group. The reply listed two omissions (the filter, and the circle that used it, each with its line and column), two approximations (each rounded rectangle's corners became cubic curves, with a maximum radial error of 0.000034 units) and six plain-language notes on what import changes. Each source id maps to a new item id (output → svg-2) and stays as the item's name.
  4. One atomic edit in a saved session: recolour output to #2e8b57 and move input 10 units down, giving revision 1.
  5. The same request resent with the same request_id: the original receipt came back, and the session stayed at revision 1.
  6. Preview: a 240 × 120 PNG returned as an MCP image in the reply, so the agent sees the result without writing a file. Its pixels match the published PNG's.
  7. Publish: revision 0 as SVG before the edit, then revision 1 as SVG and PNG. Publishing revision 1 again to the same file name was refused with OUTPUT_EXISTS ("Existing files are never overwritten"), and the existing file's hash didn't change.
  8. Undo gave revision 2. Its published SVG was byte-identical to the SVG published before the edit.
  9. A stale edit (expected revision 0 while the session was at 2) was refused with REVISION_CONFLICT.
  10. The source SVG had the same SHA-256 after the run.

To repeat it: download the release archive, then run python -I inkbolt_probe.py <path to inkbolt.exe> <path of a folder that doesn't exist yet> diagram.svg out.json with the files in data/ (Python 3, standard library only); the probe creates the folder. Your timings and reply byte counts (which include the folder path) will differ; the outcomes and the SVG hashes should match ours.

Each tool, and when to choose it over Inkbolt

SVGMaker MCP

GenWaveLLC/svgmaker-mcp (npm @genwave/svgmaker-mcp 2.1.0) is a TypeScript client for SVGMaker's hosted AI service, and ranked for two of our three searches. Run locally, it exits unless SVGMAKER_API_KEY is set; the hosted server at mcp.svgmaker.io signs you in with an SVGMaker account instead. It advertises 17 tools on each transport: generate an SVG from a prompt, "edit" (send an image or SVG with a prompt and receive a new AI-made SVG, not an element-level change), convert a raster image to SVG with AI, remove a background, manage your past generations and a public gallery, and, run locally, preview a local file as PNG (the hosted server swaps that tool for an upload tool). Generate, edit and convert run on SVGMaker's servers, and local input files are uploaded. The client sets a default limit of 2 requests a minute (SVGMAKER_RATE_LIMIT_RPM raises it); SVGMaker's API documentation lists 5 requests a minute for generate and edit, and credits per call (generate 1 to 3, edit 2 to 5, AI vectorise 1, background removal 1). Downloading past generations needs a paid account. New accounts get 6 free credits, then a daily top-up to 3, and free-plan generations are public. Its pricing page didn't show plan prices when we read it, so we can't quote them.

Choose it when you want new artwork from a text description, or an AI conversion of a photo or logo, and you accept an account, credits and uploading your images. Choose Inkbolt when the agent must make exact changes to a specific drawing, such as one colour or one position, and check, retry or undo them offline.

inkscape-mcp (sandraschi)

sandraschi/inkscape-mcp (MIT, 88 stars) is a Python server over the Inkscape command line and the SVG's XML. Its source registers 19 tools that each take an operation, about 110 operations in all (its docs say 17 tools and 60+ operations): attribute edits by object id, restyling by CSS-like selector, path and boolean operations, layers, gradients, text on paths, animation, bitmap tracing, and conversion to PDF, EPS, PS, PNG, WMF, EMF, XAML and DXF (its code also accepts AI and CDR). Its editing calls work on files: XML edits write back to the input file unless you name an output, previews are PNG files on disk, and there is no session or undo. Some tools generate SVG with your MCP client's own model (the client must support MCP sampling). Most operations need Inkscape installed; its by-id XML edits don't. By default it also starts a Prometheus metrics server on port 9074; it can search inkscape.org's extension gallery and install extensions from it (verified ones only by default), send actions to a running Inkscape window, and post to other local MCP servers (Blender, Unity, GIMP). A configured list of allowed folders exists, but nothing in the code enforces it.

Choose it when you use Inkscape already and want a broad set of Inkscape operations (about 110) plus its extras: AI generation through your MCP client, the inkscape.org extension gallery and links to other local MCP servers. Choose Inkbolt when you want no desktop app to install, revisions with undo and safe retries, and outputs that never replace your files.

inkscape_mcp (aravindev)

aravindev/inkscape_mcp (MIT, 79 stars, PyPI inkscape-mcp 1.3.1) is a declared fork of sandraschi's server, retargeted at Linux and Windows. It has 8 tools with 108 operations in two modes. Headless, it runs the Inkscape command line or edits the XML of a file, with object ids checked against each operation's scope. Live, it drives a running Inkscape over D-Bus (and on Windows launches one): it can edit the open document by id or XPath, insert SVG fragments, and each edit becomes one step in Inkscape's own undo. Live mode saves the document after every change unless you set INKSCAPE_MCP_AUTO_SAVE=0, and one operation runs arbitrary Python inside Inkscape. Previews are PNG files on disk. On start it installs its own extensions into your Inkscape profile when they are missing or a different version. We found no network calls in its code.

Choose it when you want to watch the drawing change in Inkscape and undo there, or need Inkscape's extensions and formats. Choose Inkbolt for headless runs with no GUI app on the machine, previews the agent sees in its reply, revisions it can retry and diff, and raster editing in the same tool.

image2svg-mcp

botmonster/image2svg-mcp (Apache-2.0, PyPI 1.0.1) has one tool, convert_image_to_svg, which traces a raster image with vtracer and returns SVG text, with vtracer's settings (colour or binary, spline or polygon curves, speckle filter, precision). It takes a base64 image or a URL, writes no files, needs no key, and reads local files only from a folder you allow at launch. It will fetch any http or https URL it is given.

Choose it to turn a logo, icon or photo into smooth SVG curves, free and locally. Choose Inkbolt to edit the result afterwards. Inkbolt also traces (image.trace), but it follows pixel edges exactly, with no smooth curve fitting, which suits pixel art and flat icons rather than photos.

svg-maker-mcp

erkamkavak/svg-maker-mcp has 10 tools for SVG text that the agent writes itself: render it to a PNG the agent sees, optimise it with SVGO, format and validate it, read its metadata, and convert it to React or React Native components or a data URI, plus one prompt for designing an icon. It keeps no document and reads no files; saving writes a file anywhere the process can write, over any existing one. The repository has no licence file (its package.json says ISC), and its README's launch command doesn't set MCP_RUN_LOCAL=true, which the code needs before it starts the stdio server.

Choose it when the agent hand-writes SVG and wants a quick render, SVGO and React output in one place. Choose Inkbolt when it should work on a document rather than retype SVG text on every change.

EditItAll MCP

Subcue/edititall-mcp (npm @edititall/mcp 0.2.1) starts a headless Chrome, Edge, Chromium or Brave and loads EditItAll's closed-source web editors from edititall.com, then drives them with 18 tools for spreadsheets, PDFs, Word documents, slides and images. For vectors there is one tool: it opens SVG text in the web vector editor, and another tool takes a screenshot of the editor page. There is no tool to edit an element or to export a vector file. Its README says files are processed on your device; the editors that do the work aren't in the repository, so we couldn't check that.

Choose it for PDF, spreadsheet and image compression or conversion jobs from one server. Choose Inkbolt to edit vector shapes and export the result as a file.

LayerBack MCP

TopLocalAI/layerback-mcp (npm layerback-mcp 0.1.2) uploads a diagram image (PNG, JPEG or WebP) to LayerBack's hosted service, which rebuilds it as editable VSDX, PPTX, draw.io or SVG. It has 3 tools and needs an API key. Each conversion through the API, which the MCP uses, costs 10 credits and includes every format (on LayerBack's website, downloading or editing a conversion costs 10 credits). Plans are US$20, $40 and $80 a month for 1,000, 3,000 and 10,000 credits (half that billed yearly). Its API docs list 20 conversions an hour per account (the top plan advertises higher limits); its README says uploads are deleted within 72 hours, while its API docs say results are kept for at least 72 hours.

Choose it to turn a screenshot of a diagram into an editable Visio, PowerPoint or draw.io file. Choose Inkbolt to draw or edit the diagram itself.

Illustrator MCP bridges

The "Illustrator MCP Server" on Glama is slashprint/illustrator-mcp, an extended copy of krVatsal/illustrator-mcp (165 stars). slashprint's source registers 28 tools (its README and Glama's page describe 5 to 7): run any ExtendScript in a running Illustrator through COM on Windows or AppleScript on macOS, open and save documents, render an artboard as a PNG in the reply, position and align items by name, fonts and layout helpers, and design checks. Its view tool brings Illustrator to the front and screenshots the whole screen, including other windows. The playbooks.com entry (its page returned 404 on 18 October) pointed to AnshulDalua/illustrator-mcp, a macOS-only copy of spencerhhubert/illustrator-mcp-server with two tools. None of these four repositories has a licence.

Choose one when your artwork and workflow are in Illustrator and you have it installed. Choose Inkbolt when you want typed, checked edits instead of scripts, nothing on your screen, and a tool licensed for reuse.

Inkbolt's limits

  • It rewrites the SVG it exports. Import turns the file into Inkbolt's own document, and export writes new markup: in our run, rectangles became paths (rounded corners as cubic curves), ids became svg-1 to svg-4 with each source id kept as a <title>, and the gradient was renamed; our 833-byte input came back as 2,736 bytes. Text is exported as one path per glyph, so the SVG it writes has no live text (per its docs; our test drawing had no text). Classes, selectors, comments and formatting are not kept, and colours are stored as 8-bit RGBA; its own import report says so. If the job is to change one attribute and keep everything else in a hand-written file as it was, a tool that edits the XML directly changes less of it (we didn't test how much of a file the Inkscape servers keep).
  • Strict by default. SVG features it doesn't support, such as filters and animation, stop the import. With omit_and_report the import goes ahead and lists what was dropped, but the element that used the feature goes too: our blurred circle disappeared entirely.
  • Text needs a font file you supply. An SVG with any <text> element fails to import, even with omit_and_report, until you import a font (with its licence file) through font.import and bind it to each font family, weight and style the SVG uses. There is no fallback to installed system fonts.
  • It doesn't generate artwork from a prompt. The agent composes the shapes; for AI-made illustrations use a generator such as SVGMaker.
  • Its tracer follows pixel edges exactly and has no smooth curve fitting or photo reconstruction (per its docs).
  • The tool definitions are large. The core catalogue is 22 tools but 85 KB of definitions; the full catalogue is 4 MB, so use the documented --tools core launch.
  • Replies are large by default. Session create, apply and read return the whole document: about 11 KB per edit for our four-shape test drawing, and the 16-call task's replies came to 104 KB in all. A compact response mode (response_mode: "compact" on those session calls) returns less; we didn't measure it.
  • Background export jobs need Windows. Its core editing, MCP server and sessions are verified on Windows, Linux and macOS; some newer storage work is verified only on Windows and on Linux under WSL (per its README and docs/PLATFORMS.md). We ran it on Windows only.
  • It is young: version 0.82.0 (16 October 2026), 1 GitHub star. main adds raster features that aren't in the release. It is in the official MCP Registry as io.github.skulitom/inkbolt.

On 18 October its GitHub repository returned 404, there is no npm package, and we found no archived copy, so it can't be installed from its README; Glama still lists it.
  • ws-buntu/inkscape-mcp-server, the "Inkscape MCP Server" that ranked on Glama, has no server code in its repository: only a README, a pyproject.toml, a licence and an image.
  • Other Inkscape servers we didn't read: Shriinivas/inkmcp (75 stars, AGPL-3.0) and grumpydevorg/inkscape-mcps (55 stars), plus several with fewer than 10 stars on Glama.

Method

  • The searches this page answers, run on 18 October 2026: "SVG vector graphics editing MCP server comparison", "SVG editing MCP server for AI agents local" and "best MCP server for vector graphics and image editing Claude Code". Directory pages (Glama, Playbooks, Enterprise DNA) filled most results, with a few blog round-ups. Two summaries said they found no independent head-to-head comparison or no clear winner. Inkbolt appeared in none.
  • Which tools: the SVG and vector MCP servers with a real repository that ranked in those results: SVGMaker MCP, image2svg-mcp, svg-maker-mcp, EditItAll, LayerBack and the Illustrator bridge; for Inkscape, the two most starred servers listed on Glama, because the one that ranked has no code. The rest are under "Also in the results".
  • Inkbolt was measured as described above: the 0.82.0 Windows x64 release download, and main at f189cc3 built with cargo build --release --locked in 2 minutes 48 seconds. Its SVG import source files are unchanged between the two (main raises a shared image-size limit).
  • The other tools were not installed or run. We run another tool only when it is open source from its official source, works offline with no account or key, and can't reach the network or your desktop beyond its own install. None of the eight met all three: SVGMaker and LayerBack need accounts and upload files, EditItAll loads remote code, the Inkscape servers and the Illustrator bridges drive desktop apps (or, for sandraschi's, open a metrics port and download extensions), image2svg-mcp fetches any URL it is given, and svg-maker-mcp has no licence file. So only Inkbolt's claims are tested here; the other columns describe what each tool's code and docs say, not how well it works. We read each README, the source files named below and the hosted services' own pages, and counted MCP tools where each server registers them. Stars and versions come from GitHub, npm and PyPI on 18 October 2026.
